Phase 1: Foundation Services (Build First)
1. User Service (Identity & Authentication)

Tech Stack: Go (for performance and concurrency in auth flows)

Purpose: Central identity management, authentication, and user profile data
Core Functionalities:

    User registration and KYC workflow orchestration
    Authentication (OAuth2/JWT token issuance)
    User profile management (personal details, preferences)
    Session management and device tracking
    2FA/MFA enforcement

Key APIs:

    POST /api/v1/users/register - Create new user
     controller/Handler:
      Service Layer:
        Successful:
          - Check for existing email
          - Hash Password
          - Persist data
          - Generate verification token
          - Publish Event
          - Respond with data and error (nil)
        User already Exists:
          - Check For Existing email
          - respond with error
    POST /api/v1/users/login - Authenticate user
    POST /api/v1/users/verify-otp - Verify 2FA code
    GET /api/v1/users/{userId}/profile - Get user profile
    PUT /api/v1/users/{userId}/profile - Update profile
    POST /api/v1/users/refresh-token - Refresh JWT

Data Models:

    User (userId, email, phoneNumber, passwordHash, kycStatus, createdAt)
    Session (sessionId, userId, deviceId, tokenHash, expiresAt)
    KYCDocument (documentId, userId, documentType, verificationStatus)

Database:

PostgreSQL (ACID compliance for user data, strong consistency required)
Dependencies:

External KYC providers (Jumio, Onfido), SMS/Email providers (Twilio, SendGrid)
